# YouTube Clone UI

A responsive YouTube-inspired frontend prototype built with HTML, CSS, and JavaScript. The project recreates the core layout and user interface of YouTube, including a navigation sidebar, search bar, video thumbnail grid, and a video playback page.

## Features

* Responsive homepage layout
* Sidebar navigation menu
* Search bar UI
* Video thumbnail cards
* Demo video playback page
* Clean and modern design

## Project Structure

* `index.html` – Main YouTube-style homepage
* `play-video.html` – Demo video playback page
* `style.css` – Styling and responsive layout
* `script.js` – Sidebar toggle functionality
* `images/` – Icons, thumbnails, and UI assets

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Purpose

This project was created to practice frontend web development skills by replicating the design and layout of a popular video streaming platform.
